Atmosphere Weather App

An interactive weather dashboard built with HTML, CSS, and vanilla JavaScript.

Run locally

Open this folder in VS Code.

Install the Live Server extension if needed.

Right-click index.html and select Open with Live Server.

You can also open index.html directly in a modern browser.

Features

Search for cities worldwide

Use your current location

Current weather and 24-hour forecast

Seven-day outlook

Air quality, PM2.5, and PM10

Wind, humidity, UV, pressure, precipitation, sunrise, and sunset

Celsius/Fahrenheit toggle

Saved cities using browser local storage

Responsive mobile and desktop layouts

Data source

The app uses the free Open-Meteo Forecast, Air Quality, and Geocoding APIs. No API key is required.

Files

index.html — page structure

styles.css — visual design and responsive layout

app.js — API requests and interactions
